Einmalige Einrichtung: gemeinsamer Speicher

Damit alle 4 Personen von ihren eigenen Geräten abstimmen und die Stimmen zusammenlaufen, wird ein kostenloser Cloud-Speicher (JSONBin.io) genutzt. Einmal einrichten – gilt dann für alle 4 Wochen.

  1. Auf jsonbin.io kostenlos registrieren.
  2. Unter API Keys einen Access Key mit den Rechten read + update anlegen (nicht den Master Key verwenden).
  3. Einen Bin anlegen (Inhalt {} genügt) und dessen BIN ID kopieren.
  4. Beide Werte eintragen und auf „Verbinden“ klicken.
